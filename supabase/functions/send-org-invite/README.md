# send-org-invite

Στέλνει πραγματικό email πρόσκλησης όταν ο ιδιοκτήτης ενός οργανισμού
προσθέτει μέλος στην ομάδα (κουμπί «Πρόσκληση» στις Ρυθμίσεις → Οργανισμός & Ομάδα).

Η εγγραφή στη βάση (`organization_members`, μέσω `invite_org_member`) παραμένει η
πηγή αλήθειας. Το email είναι φιλική ειδοποίηση: αν αποτύχει, το μέλος αποκτά
πρόσβαση κανονικά μόλις δημιουργήσει λογαριασμό με το ίδιο email.

## Ασφάλεια

Εκτελείται με το JWT του καλούντος (όχι service role). Επιβεβαιώνει, μέσω RLS,
ότι ο καλών είναι ιδιοκτήτης οργανισμού και ότι το email ανήκει όντως σε
προσκεκλημένο μέλος του, ώστε να μη γίνεται εργαλείο αποστολής σε αυθαίρετες
διευθύνσεις.

## Ενεργοποίηση

```bash
# Τα RESEND_API_KEY / SUPABASE_URL / SUPABASE_ANON_KEY υπάρχουν ήδη
supabase functions deploy send-org-invite
```

Καλείται αυτόματα από την εφαρμογή με `supabase.functions.invoke('send-org-invite', { body: { email } })`.
