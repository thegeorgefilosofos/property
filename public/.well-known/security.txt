#
#  Δεν στρεφόμαστε νομικά, ούτε ζητάμε από τρίτους να στραφούν, εναντίον
#  ερευνητή που τηρεί τους όρους της ενότητας 2. Θεωρούμε την έρευνά του
#  εξουσιοδοτημένη πρόσβαση κατά την έννοια του άρθρου 370Β του Ποινικού
#  Κώδικα και δεν την αναφέρουμε ως αξιόποινη πράξη.
#
#  Αν τρίτος κινηθεί εναντίον σου για έρευνα που έγινε εντός αυτών των όρων,
#  γράψε μας: το δηλώνουμε εγγράφως ότι είχε τη συγκατάθεσή μας.
#
#  Ο λιμένας καλύπτει την έρευνα, όχι ό,τι ακολουθεί. Δημοσίευση δεδομένων
#  τρίτων, εκβίαση για αμοιβή ή πώληση του ευρήματος βγαίνουν εκτός του,
#  αυτομάτως και ανεξάρτητα από το πόσο σοβαρή ήταν η ευπάθεια.

# ── 2. Τι ζητάμε από εσένα ─────────────────────────────────────────────────
#
#  · Ειδοποίησέ μας πρώτους και δώσε 90 ημέρες πριν δημοσιεύσεις. Αν η
#    διόρθωση αργεί περισσότερο, θα σου πούμε γιατί και θα συμφωνήσουμε νέα
#    ημερομηνία — δεν την παρατείνουμε μονομερώς.
#  · Σταμάτα στο ελάχιστο που αποδεικνύει το εύρημα. Μην αποκτήσεις, μην
#    αντιγράψεις, μη διαγράψεις και μην τροποποιήσεις δεδομένα τρίτων. Αν
#    πέσεις πάνω σε προσωπικά δεδομένα, σταμάτα και γράψε μας.
#  · Μην υποβαθμίσεις την υπηρεσία: χωρίς DoS, χωρίς spam, χωρίς μαζικές
#    δοκιμές κωδικών σε λογαριασμούς χρηστών.
#  · Χωρίς κοινωνική μηχανική σε χρήστες ή προσωπικό και χωρίς φυσική
#    πρόσβαση σε εγκαταστάσεις.
#  · Δοκίμασε σε δικό σου λογαριασμό. Δημιουργείς όσους θέλεις, δωρεάν.

# ── 3. Τι κάνουμε εμείς ────────────────────────────────────────────────────
#
#  · Επιβεβαιώνουμε την παραλαβή εντός 3 εργάσιμων ημερών.

#    κρίνουμε, εντός 10 εργάσιμων ημερών.
#  · Σε κρατάμε ενήμερο τουλάχιστον κάθε 14 ημέρες μέχρι να κλείσει.
#  · Σε αναφέρουμε ονομαστικά στο σημείωμα διόρθωσης, αν το θέλεις.

#  Δεν υπάρχει χρηματική αμοιβή (bug bounty). Το λέμε από την αρχή αντί να
