# Οι τρεις δουλειές: το τεστ που ανεβάζει την απλότητα από 7 σε 8

Αυτό το έγγραφο είναι έτοιμο προς χρήση. Δεν χρειάζεται προετοιμασία πέρα από
έναν λογαριασμό δοκιμαστή και είκοσι λεπτά ανά άτομο.

---

## Ο κανόνας του τεστ, σε τέσσερις γραμμές

1. **Πέντε δοκιμαστές.** Ιδιοκτήτες ακινήτου που δεν έχουν ξαναδεί την εφαρμογή.
2. **Τρεις δουλειές ο καθένας**, με τη σειρά που γράφονται εδώ.
3. **Καμία βοήθεια.** Ούτε υπόδειξη, ούτε «κοίτα εκεί», ούτε απάντηση σε ερώτηση.
4. **Το 8,0 δίνεται με πέντε στα πέντε σε καθεμία** και μηδέν ερωτήσεις προς εσένα.

Αν κάποιος κολλήσει πάνω από πέντε λεπτά σε μία δουλειά, σταματά εκεί. Είναι
αποτυχία και είναι η πιο χρήσιμη πληροφορία που θα πάρεις όλη τη μέρα.

---

## Πριν καθίσει ο δοκιμαστής

- Ενας λογαριασμός δοκιμαστή, καθαρός. **Κανένα ακίνητο καταχωρημένο.** Το τεστ
  ξεκινά από το ίδιο σημείο με κάθε νέο χρήστη.
- Δικό του κινητό ή ταμπλέτα, όχι δικό σου. Θέλουμε το μέγεθος οθόνης που έχει
  στην πραγματικότητα.
- Ενας λογαριασμός ΔΕΗ ή κοινοχρήστων σε χαρτί, δικός του ή τυπωμένος από εσένα.
- Χρονόμετρο. Το κινητό σου αρκεί.
- Εσύ **δεν μιλάς**. Κρατάς σημειώσεις και μετράς. Αυτή είναι όλη η δουλειά σου.

Διάβασέ του αυτό, μία φορά, πριν αρχίσει:

> «Θα σου δώσω τρεις δουλειές. Κάνε τες όπως θα τις έκανες μόνος σου στο σπίτι.
> Δεν δοκιμάζεσαι εσύ, δοκιμάζεται η εφαρμογή. Αν κάτι δεν βρίσκεται, το λάθος
> είναι δικό μου. Πες φωναχτά τι σκέφτεσαι όποτε θέλεις. Δεν θα σου απαντήσω σε
> ερωτήσεις όσο δουλεύεις, όχι από αγένεια, αλλά επειδή στο σπίτι δεν θα είμαι
> εκεί να απαντήσω.»

---

## ΔΟΥΛΕΙΑ 1: η δαπάνη από τον λογαριασμό

**Δώσ' του το χαρτί και διάβασε αυτό, αυτολεξεί:**

> «Κρατάς στο χέρι σου έναν λογαριασμό που πλήρωσες για το ακίνητό σου. Θέλω να
> τον περάσεις στην εφαρμογή, ώστε να μετρήσει στα έξοδα της χρονιάς.»

**Τίποτε άλλο.** Δεν λες «τράβα φωτογραφία», δεν λες «πήγαινε στις Δαπάνες».

**Ολοκληρωμένη όταν:** η δαπάνη φαίνεται στη λίστα δαπανών, με σωστό ποσό και
σωστή ημερομηνία.

**Χρόνος στόχος:** 3 λεπτά. **Οριο εγκατάλειψης:** 5 λεπτά.

**Τι σημειώνεις:**

| Ερώτηση | Απάντηση |
|---|---|
| Χρόνος ώς την ολοκλήρωση | |
| Δοκίμασε φωτογραφία ή πληκτρολόγησε; | |
| Πόσες φορές πήγε σε λάθος οθόνη πριν βρει τη σωστή; | |
| Το ποσό μπήκε σωστό με την πρώτη; | |
| Τι είπε φωναχτά, κατά λέξη, στο πρώτο σημείο που δίστασε | |

---

## ΔΟΥΛΕΙΑ 2: ο φόρος της χρονιάς

**Διάβασε αυτό, αυτολεξεί:**

> «Το ακίνητο που μόλις καταχώρησες το νοικιάζεις με 500 ευρώ τον μήνα, όλη τη
> χρονιά. Θέλω να μου πεις πόσο φόρο θα πληρώσεις γι' αυτό.»

Αν δεν έχει καταχωρήσει ενοίκιο στη Δουλειά 1, θα χρειαστεί να το κάνει τώρα.
**Αυτό είναι μέρος της δουλειάς και δεν τον βοηθάς να το βρει.**

**Ολοκληρωμένη όταν:** λέει έναν αριθμό σε ευρώ και μου δείχνει πού τον είδε.

**Χρόνος στόχος:** 4 λεπτά. **Οριο εγκατάλειψης:** 5 λεπτά.

**Τι σημειώνεις:**

| Ερώτηση | Απάντηση |
|---|---|
| Χρόνος ώς την ολοκλήρωση | |
| Ποιον αριθμό είπε | |
| Είναι ο σωστός, ή διάβασε άλλο νούμερο για φόρο; | |
| Από ποια καρτέλα τον διάβασε | |
| Κατάλαβε ότι το 500 έπρεπε να το καταχωρήσει πρώτα; | |

**Προσοχή σε αυτό:** αν δείξει το ΕΝΦΙΑ ή το χαρτόσημο αντί για τον φόρο
εισοδήματος, η δουλειά ΔΕΝ ολοκληρώθηκε. Το ότι βρήκε «έναν φόρο» δεν μετράει.
Σημείωσέ το: σημαίνει ότι η οθόνη δείχνει τρία νούμερα και δεν λέει ποιο είναι
ποιο.

---

## ΔΟΥΛΕΙΑ 3: μπήκε το ενοίκιο

**Διάβασε αυτό, αυτολεξεί:**

> «Σήμερα ο ενοικιαστής σου κατέθεσε το ενοίκιο του μήνα. Πες το στην εφαρμογή.»

**Ολοκληρωμένη όταν:** ο μήνας φαίνεται εξοφλημένος και το ποσό μπήκε στα έσοδα.

**Χρόνος στόχος:** 2 λεπτά. **Οριο εγκατάλειψης:** 5 λεπτά.

**Τι σημειώνεις:**

| Ερώτηση | Απάντηση |
|---|---|
| Χρόνος ώς την ολοκλήρωση | |
| Από πού το έκανε (Επισκόπηση, Ενοικιαστής, βοηθός, άλλο) | |
| Χρειάστηκε να ψάξει σε δεύτερη καρτέλα; | |
| Πίστεψε ότι το έκανε πριν το κάνει; | |

---

## Οι τρεις ερωτήσεις του τέλους

Μετά και από τις τρεις, ρώτησέ τον αυτά και **γράψε τα λόγια του, όχι τη
σύνοψή σου**:

1. «Τι σου φάνηκε πιο δύσκολο απ' όσο περίμενες;»
2. «Υπήρξε στιγμή που σκέφτηκες να τα παρατήσεις; Πού;»
3. «Θα το χρησιμοποιούσες τον επόμενο μήνα; Γιατί ναι ή γιατί όχι;»

Η τρίτη δεν βαθμολογεί την απλότητα. Την κρατάς για την επικύρωση αγοράς, που
είναι το επίπεδο με τον χαμηλότερο βαθμό όλου του πίνακα.

---

## Το φύλλο βαθμολογίας

Ενα κουτί ανά δοκιμαστή και δουλειά. Μπαίνει **Ν** για ολοκληρώθηκε χωρίς
βοήθεια και χωρίς ερώτηση, **Ο** για οτιδήποτε άλλο.

| | Δ1 δαπάνη | Δ2 φόρος | Δ3 ενοίκιο |
|---|---|---|---|
| Δοκιμαστής 1 | | | |
| Δοκιμαστής 2 | | | |
| Δοκιμαστής 3 | | | |
| Δοκιμαστής 4 | | | |
| Δοκιμαστής 5 | | | |

**Δεκαπέντε Ν σημαίνει 8,0 στην απλότητα και το UX.** Δεκατέσσερα δεν σημαίνει.

Το κουτί που θα βγει Ο είναι ο λόγος που γίνεται το τεστ: εκεί κρύβεται η
διόρθωση που καμία μέτρηση σε Chromium δεν βρίσκει, επειδή δεν είναι θέμα
διάταξης αλλά θέμα του τι περιμένει ο άνθρωπος να δει.

---

## Τι ΔΕΝ κάνει αυτό το τεστ

Δεν λέει αν η εφαρμογή είναι όμορφη, αν οι υπολογισμοί είναι σωστοί ή αν κάποιος
θα πληρώσει. Μετρά ένα πράγμα: **αν ένας ιδιοκτήτης, μόνος του, τελειώνει τις
τρεις δουλειές για τις οποίες υπάρχει η εφαρμογή.**

Αν βγουν δεκαπέντε Ν, ο βαθμός πάει 8,0 και ο επόμενος όρος είναι ο χρόνος της
πρώτης μέρας. Αν βγουν λιγότερα, ο βαθμός μένει 7,0 και τα Ο γράφουν μόνα τους
τη λίστα της επόμενης εβδομάδας.
