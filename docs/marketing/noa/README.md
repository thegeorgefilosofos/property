# Το σήμα της Νόα

Ο δακτύλιος **δεν είναι διακόσμηση**: είναι μετρητής. Νόα μετράει χρόνο που
τρέχει προς μια προθεσμία, και το σήμα το λέει. Στα βίντεο ο δακτύλιος κλείνει
όσο πλησιάζει η ημερομηνία· η γεννήτρια αναρτήσεων
(`npm run posts`) τον υπολογίζει από τις πραγματικές ημέρες που απομένουν.

| Αρχείο | Πού |
|---|---|
| `noa-mark-light.png` (1024) | Φωτογραφία προφίλ, ανοιχτό φόντο |
| `noa-mark-dark.png` (1024) | Φωτογραφία προφίλ, σκοτεινό φόντο |
| `noa-mark-small.png` (96) | Υδατογράφημα πάνω δεξιά στα βίντεο |
| `noa-mark-*.svg` | Για μοντάζ, με τη γραμματοσειρά του προϊόντος |

## Γιατί δεν είναι πρόσωπο

Το `lib/assistant/identity.ts` ορίζει δεσμευτικά ότι **Νόα δεν έχει φύλο**, και
ο `scripts/guard-assistant-name.mjs` το επιβάλλει σε 245 αρχεία. Κάθε ρεαλιστικό
ανθρώπινο πρόσωπο διαβάζεται ως άντρας ή γυναίκα. Οπότε Νόα εμφανίζεται ως
**φωνή, χέρια, τυπογραφία και αυτό το σήμα**.

Αν ποτέ αποφασιστεί πρόσωπο, αλλάζει πρώτα ο κανόνας και ο φύλακας, και ισχύουν
τρία πράγματα χωρίς εξαίρεση: δηλώνεται ως τεχνητό, δεν παριστάνει λογιστή, και
δεν δίνει προσωπική φορολογική συμβουλή.
